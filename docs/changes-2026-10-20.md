## 2. 개인정보·보관 정책

- **세션 2시간**(`SESSION_TTL_HOURS`, 기본 24 → 2). 지나면 조회는 즉시 `410 SESSION_EXPIRED`이고 worker가 분석 결과와 사고 제목(파일명)을 지운다.
- **저장에 동의한 사용자**: 비식별 영상과 분석 결과를 90일(`RETENTION_DAYS`) 보관하되 화면에는 다시 보여 주지 않는다(데이터셋 용도).
- **결과 지우기**(`DELETE /accidents/{id}`): 동의 여부와 상관없이 결과와 영상을 즉시 삭제. 결과 화면에 자동 삭제 시각과 버튼이 있다.
- 브라우저는 만료 시각을 기억해 지나면 접근 정보를 지우고 삭제 안내를 보여 준다.
- 동의 문구와 `CONSENT_VERSION`(`2026-10-20.2`)을 새 정책에 맞췄다. **법무 확인 필요**: [review/consent-review.md](review/consent-review.md).
- DB 스키마 변경 없음(마이그레이션 불필요).

## 3. 가감요소: 7개 → 122개 유형

손해보험협회 과실비율 인정기준(2023.06) PDF에서 팀원이 뽑은 규칙을 합쳤다.

- **데이터**: `adjustment_rules.json`(유형 122개, 규칙 838개 추가), `factor_labels.json`, 쉬운 말 48개(`adjustment_explanations.json`, 초안). 합치는 도구는 `backend/tools/merge_pdf_rules.py`이며 합치기 전에 과실표와 기본 비율·진행 이름을 대조한다. PDF와 과실표가 다른 **11개 유형은 일부러 뺐다**(`pdf_rules_blocked.json`).
- **자동 대조**: 규칙 838개의 원문 행·수치·A/B 대응이 추출본과 전부 일치(사람이 숫자를 하나하나 볼 필요가 크게 줄었다).
- **엔진 수정**: 서로 양립하지 않는 답(서행 불이행 / 서행 또는 일시정지)은 다시 묻고, 원문이 불분명한 7개 유형은 최종 비율을 확정하지 않는다.
- **새 규칙은 전부 사용자가 직접 확인**(`manual_only`). 영상 AI의 관찰은 "AI 제안"으로만 보인다. 기존 7개 유형은 기존 자동 적용 동작을 그대로 둔다.
- **확인한 유형만 서비스에 켠다**(`AVLY_REQUIRE_RULE_REVIEW=1`, 기본). 새 유형은 `reviewed: true`가 되기 전에는 "미등록"(기본 비율만 안내)이다. 개발에서 전부 보려면 `0`.
- 팀원 자료 폴더 `backend/assets/`는 이름과 내용이 뒤섞여 있어 이름을 바로잡아 달라고 요청해야 한다. git에서는 제외했다(88MB 포함).

## 5. 판례

- PDF의 도표마다 실린 참고 판례(법원·선고일·사건번호·요약)를 파싱해 유형별 판례(`verified_cases.json`)로 옮겼다(`tools/build_chart_cases.py`).
- **133개 중 99개 유형**에 연결(3건 채움 45개, 1~2건 54개), 총 209건. 민사 과실 사건번호만 쓰고 형사·행정은 뺐다.
- 3건이 채워진 유형은 법령 API 검색을 하지 않는다. 못 붙인 34개 유형은 기존 검색을 쓴다.
- 판결문 원문이 아니라 **협회 도표의 요약을 파싱한 것**이라 화면에 "검수 전"으로 표시된다. 주차장 유형(126, 127)은 도표에 판례가 1건뿐이다.

## 6. 타임라인

- **합치기**(화면만): 끊겨 이어지는 같은 상태의 내 차 움직임을 하나로, 시작 시각이 0.5초 안인 관찰은 한 단계로 묶고 쉬운 문장과 구간 길이를 보여 준다.
- **사고 흐름**(모델): 상세 확인(2단계)에서만 접근 / 사고 직전 / 접촉 / 접촉 이후를 최대 4단계로 쓰게 했다(출력 약 +300~400토큰, 건당 비용 약 +2~3% 예상). 장면 인용 검증을 받고, 시간순이 아니거나 판단 표현·수치가 들어 있거나 접촉을 단정한 단계는 코드가 버린다.
- **시간 관계 문장**(AI 없음): "상대 차는 화면 오른쪽에서 처음 보인 뒤 약 2.0초 뒤에 접촉이 의심되는 장면이 나와요." 속도·거리·사람이 피할 수 있었는지는 말하지 않는다.
- **한계**: 실제 모델이 사고 흐름을 얼마나 안전하게 쓰는지는 시험 영상이 없어 확인하지 못했다(가짜 응답으로만 시험). 영상에 따라 내 차 움직임만 나오는 결과도 있다. 타임라인을 숨길지는 **정답 라벨 평가 뒤에 다시 정하기로 했다**.

## 7. 보고서 화면(PDF 저장)

- 결과 화면을 그대로 찍던 인쇄를 **A4 문서 형식**(`/analysis/{id}/report`)으로 교체. 한눈에 보기, 사고 상황, 과실 비율 산정 과정, 타임라인, 비슷한 판례(최대 3건), 관련 법령, 유의사항과 출처.
- 서버가 PDF를 만들지 않고 브라우저 인쇄("PDF로 저장")를 쓴다. 서버에 PDF가 남지 않아 2시간 삭제 정책과 충돌하지 않는다. 서버 PDF(WeasyPrint)는 필요해질 때 따로 결정.
- 모양 샘플(시험용 데이터): [review/report-sample.pdf](review/report-sample.pdf)

## 8. 정확도 평가와 Gemini

- **평가 도구** `backend/tools/evaluate_labels.py`: 정답이 있는 영상으로 분석이 맞는지 잰다(블랙박스 차량은 항상 A). 라벨 영상과 정답은 `backend/labels/`(git 제외, 용량).
- **1차 결과**(Gemini 무료 flash-lite, 주차장 9개): 장소 9/9, 차대차 7/9, 내 차 행동 5/9, 상대 차 행동 4/9, 후보에 정답 5/9, **1순위 정답 2/9(22%)**. 가장 큰 문제는 내 차·상대 차 행동 판단이고 126(직진 출차)과 127(후진 출차)을 바꿔 고르는 경우가 있다. 자세한 표: [review/eval-parking-gemini-lite.md](review/eval-parking-gemini-lite.md). 작은 무료 모델이라 결과가 더 낮게 나왔을 수 있어 큰 모델·OpenAI로 비교가 필요하다.
- **Gemini 전환**: 무료 구간은 모델당 하루 요청 20회, 가장 작은 모델은 결과가 흔들리고, 무료 키는 보낸 내용을 Google이 제품 개선에 쓸 수 있다. 그래서 코드는 `SJI`에 합치지 않고 **`SJI-gemini` 브랜치에 보관**했다. Gemini는 사고 흐름이 들어간 응답 형식을 거부(400)한다. 정리: [review/gemini-switch.md](review/gemini-switch.md).

## 아직 못 한 것과 결정이 필요한 것

1. **동의 문구 법무 확인**: 보관 기간(2시간, 90일), 외부 AI 전송, "전체 동의" 묶음, 세션 종료 뒤 동의 철회 방법이 없는 점.
2. **가감요소 검수**: 규칙 838개와 쉬운 문장 68개가 검수 전이다. 사람별로 나눠서 검수 페이지로 하고, 유형이 확인될 때마다 켜진다. 발표 시연 유형을 먼저 확인할 것.
3. **협회 PDF 이용 조건** 확인.
4. **정확도**: 정답 라벨과 영상이 더 필요하다(지금은 주차장 9개, 유형 2개뿐). 큰 모델·OpenAI로 같은 영상을 돌려 비교할 것.
5. **타임라인**: 실제 영상으로 사고 흐름 품질 확인 후 숨길지 결정.
6. 판례를 못 붙인 34개 유형(7, 8, 10, 13, 16~19, 30, 53~56, 58, 59, 63, 64, 67, 68, 76, 77, 95~99, 101, 102, 104, 105, 109, 128~130)은 검색 결과에 따른다.
7. 팀원 자료 폴더(`backend/assets`) 파일 이름 정리와, 팀원 패치에서 빠진 `report.py`·`snapshot.py` 수정 확인 요청.
8. 정리: 원본 `Avly.py`·노트북·`results/`, 서버 PDF 필요 여부.
