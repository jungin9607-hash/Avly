# 판례 AI 비교 검수 안내

판례와 내 사고를 비교하는 설명을 AI(OpenAI `gpt-4.1-mini`)가 씁니다. 자동 검증을 거치지만 **사람이 표본으로 읽어 확인해야 하는 부분**이 남아 있어서, 무엇을 어떻게 막는지와 무엇을 봐야 하는지 정리했습니다. 코드는 `backend/app/worker/ai_compare.py`입니다.

## 어떻게 동작하나
1. 사용자가 사고 유형과 가감요소 답을 확정하면, 그 유형에 연결된 판례(최대 3건)마다 AI를 한 번씩 부릅니다. (병렬, 약 8초)
2. AI에게 보내는 것은 **글자뿐**입니다: 사용자가 확정한 사고 상황 + 판례 본문(판시사항, 판결요지, 판결 내용 앞부분 약 8천자). 영상·이미지는 보내지 않습니다.
3. AI는 사건 개요, 법원 판단 요지, 공통점, 차이점을 쓰고, **판례에 대한 모든 말에 판결문에서 글자 그대로 복사한 구절(인용)을 붙입니다.**
4. 서버가 검사합니다. 통과하지 못한 항목은 버립니다.
5. 통과한 항목을 AI가 한 번 더 "이 인용이 이 주장을 뒷받침하는가"로 판정합니다(2차 검증). 아니라고 한 항목은 버립니다.
6. 남은 것을 DB(`case_ai`)에 저장합니다. 같은 판례·같은 사고 상황이면 AI를 다시 부르지 않고 같은 설명을 보여 줍니다.
7. 호출이 실패하거나 남은 비교 항목이 없으면 규칙 비교로 대신합니다. 도표 등록 판례(본문이 한 줄뿐)는 처음부터 규칙 비교입니다.

도로교통법 조문 목록은 AI가 아니라 판결문에서 "도로교통법 제○○조"를 찾아 만듭니다.

## 막는 것
- 판결문에 없는 인용 → 항목 삭제
- 인용과 말이 무관함(두 글자 조각 2개 이상이 겹치지 않음) → 삭제
- 인용이 주장과 반대이거나 뒷받침하지 못함(2차 검증) → 삭제
- 과실비율(%), 비율 숫자(30:70), 승소·패소, "유리/불리" 표현 → 삭제
- "내 사고에만 있는 사정"은 "판례 본문에서는 확인되지 않아요"라는 말만 허용 → 판례를 단정하면 삭제

## 아직 못 막는 것 (사람이 봐야 함)
- 인용은 있고 2차 검증도 통과했지만 **의미가 어긋난 설명**이 나올 수 있습니다. 2차 검증도 AI라서 완벽하지 않습니다.
- 판례 자체가 **내 사고와 상관없는 쟁점**인 경우: 검색으로 가져온 판례 중에는 보험사 간 구상금 협정처럼 사고 내용이 아닌 판결이 섞입니다. 아래 예시 3번이 그렇습니다. 이건 검색(`law.py`) 쪽 한계입니다.
- 본문에서 앞부분만 쓰므로(약 4천자) 뒤쪽 판단은 빠집니다.
- 판례 요약(`summary`) 약 400자는 문장 중간에서 시작할 수 있습니다.

## 실제 출력 예시 (유형 107: T자형 교차로, 내 차 왼쪽 도로 직진 ↔ 상대 오른쪽 도로 좌회전)
2026-10-19에 실제 판례와 실제 모델로 만든 결과입니다.

**1. 서울중앙지방법원 2020나85513**
- 개요: 이 판례는 T자형 교차로에서 좌회전 차량과 직진 차량 간의 사고에 관한 사례입니다.
- 법원 판단: 좌회전 차량은 '양보' 표지판이 있는 대로에서 진행 중인 차량에 진로를 양보해야 합니다.
- 공통점 "진로 양보 의무": 좌회전 차량은 진로를 양보해야 할 의무가 있습니다. ← "‘양보’ 표지판은, 대로에서 진행 중인 차량이 있을 경우 진로를 양보하여야 한다는…"
- 공통점 "전방 주시의무": 직진 차량도 전방 주시의무를 지켜야 합니다. ← "원고가 전방주시의무를 소홀히 한 과실이 가볍지 않다."

**2. 서울중앙지방법원 2018가단5153974**: 비교 항목이 2차 검증을 통과하지 못해 규칙 비교로 대체, 판단 요지 2건만 AI 설명.

**3. 서울중앙지방법원 2016나37357**
- 법원 판단: 확정된 심의위원회의 조정결정은 청구인과 피청구인 간에 합의가 성립된 것으로 본다. ← **보험사 간 협정에 대한 판단으로, 사고 내용과 무관한 판례가 섞인 예**
- 차이점 "교차로 형태": 내 사고는 T자형 교차로에서 발생하였으나, 판례는 삼거리 교차로에서 발생한 사고입니다. ← 사실상 같은 형태를 차이로 표현한 약한 항목

2차 검증을 넣기 전에는 "판례에서는 차로가 구분된 상황"이라는 설명에 "차로 구별이 없는 1차로"라는 반대되는 인용이 붙은 항목이 통과했습니다. 2차 검증이 이런 항목을 걸러냅니다.

## 검수할 것
1. AI에게 주는 지시문(`INSTRUCTIONS`, `VERIFY_INSTRUCTIONS`): 대상 독자, 문체, 금지 사항이 서비스 방침에 맞는지.
2. 금지 표현(`_BANNED`)이 충분한지, 지나치게 넓어 정상 문장을 버리지 않는지.
3. 유형별로 AI 설명을 10건 이상 읽고 아래를 표시: 인용이 주장을 뒷받침하는가 / 사고와 무관한 판례가 섞였는가 / 문장이 어색하거나 단정적인가.
4. 화면 문구: "AI가 판례 본문을 읽고 정리했어요", "AI가 판례 본문을 바탕으로 비교한 내용이에요"가 적절한지. 결과 화면에 AI라고 밝히는 위치.
5. 본문이 한 줄뿐인 도표 등록 판례의 규칙 비교 문장이 충분한지.

프롬프트나 검증을 바꾸면 `PROMPT_VERSION`을 올려 저장된 결과가 새로 만들어지게 합니다.
