# 동의 문구 검토 정리

현재 문구는 AI가 쓴 초안입니다. 법무·개인정보 담당자에게 아래 항목을 확인받아 주세요. 문구는 `frontend/src/components/home/ConsentModal.jsx`에 있고, 바꾸면 `frontend/src/api/config.js`의 `CONSENT_VERSION`도 함께 바꿉니다. (버전은 동의 기록과 함께 DB에 저장됩니다.)

## 현재 문구

**[필수] 영상 분석과 외부 AI 서비스 이용 동의**
> 올린 영상에서 번호판과 사람을 자동으로 가린 뒤, 그 영상의 일부 장면(이미지)을 외부 AI 서비스로 보내 사고 상황을 분석합니다. 자동으로 가리는 방식은 완전하지 않아서 일부가 가려지지 않을 수 있어요. 분석 결과는 손해보험협회 과실비율 인정기준과 판례 자료를 참고한 안내이며 법적 효력이 없습니다. 올린 원본 영상은 이용이 끝나면 삭제하고, 차대차 사고가 아니어서 분석하지 못한 영상은 저장에 동의하셨더라도 하루 뒤 삭제합니다.

**[선택] 영상 저장과 서비스 개선 활용 동의**
> 번호판과 사람을 가린 영상을 서비스에 저장하고, 분석 결과를 다시 확인하거나 서비스를 개선하고 새 기능을 만드는 데 활용하는 것에 동의합니다. 동의하지 않아도 분석은 이용할 수 있으며, 이 경우 영상은 이용이 끝나면 삭제됩니다.

## 실제 동작 (문구가 이와 맞아야 함)

| 항목 | 동작 |
|---|---|
| 원본 영상 | 서버에 올라가고, 비식별 처리에 쓰인다. 세션 만료(기본 2시간)에 삭제 |
| 외부로 나가는 것 | 비식별된 영상에서 뽑은 장면 이미지 (원본 아님). 현재 OpenAI로 전송 |
| 장면 이미지 저장 | 우리 서버에는 저장하지 않음 (외부 서비스 쪽 보관은 계약 설정에 따름) |
| 저장 동의 없음 | 비식별 영상도 세션 만료 시 삭제 |
| 저장 동의 있음 | 비식별 영상과 분석 결과(AI 분석, 사용자가 확정한 값)를 90일(`RETENTION_DAYS`) 보관한 뒤 삭제. 사용자에게 다시 보여 주지 않는다. 사고 제목(파일 이름)은 세션이 끝나면 지운다 |
| 차대차가 아닌 영상 | 동의와 무관하게 하루 뒤 원본·비식별본 모두 삭제 |
| 분석 결과(과실비율 등) | 저장 동의 **없음**: 세션 만료(2시간)에 DB에서 지운다. 저장 동의 **있음**: 위처럼 90일 보관. 조회는 어느 쪽이든 세션 만료 즉시 불가. 화면의 '결과 지우기'는 동의 여부와 상관없이 바로 지운다(동의 철회). AI 호출 기록(토큰 수)과 사고 행은 개인정보 없이 남는다 |

## 판례 비교에 쓰는 외부 AI 전송 (추가)
판례 비교 설명을 만들 때 OpenAI로 **글자만** 보냅니다. 보내는 것은 사용자가 확정한 사고 상황(장소, 유형, 내 차·상대 차의 진행, 가감요소 답)과 공개된 판례 본문이며, 영상이나 이미지는 보내지 않습니다. 영상 분석 때 이미지가 나가는 것과는 별개이므로, 동의 문구의 "외부 AI 서비스" 고지에 이 내용이 포함되는지 확인해 주세요.

## 전체 동의 버튼 (추가)
동의 화면 맨 위에 "전체 동의"가 있다. 필수 2개(분석 동의, 당사자 영상 확인)와 선택 1개(저장·활용)를 한 번에 켜고 끈다. 각 항목은 따로 바꿀 수 있고 모두 켜져 있을 때만 전체 동의가 켜진다.
법무에 확인할 것: 선택 동의를 "전체 동의"에 묶어도 되는지(항목별 구분과 개별 해제가 보장되면 일반적으로 쓰는 방식이지만 확인 필요), 세션이 끝난 뒤에는 로그인이 없어 동의 철회(삭제 요청)를 받을 방법이 없는 점.

## 확인해 주세요

1. **국외 이전**: OpenAI(미국) 또는 Gemini(구글)로 이미지가 나간다. 개인정보 보호법상 국외 이전 고지·동의 항목(받는 자, 국가, 항목, 목적, 보유기간, 거부 방법)을 갖춰야 하는지.
2. **비식별 영상이 개인정보인지**: 번호판·사람을 가려도 장소·차종·상황으로 식별될 수 있다. 가명처리 수준으로 보는지, 개인정보로 보고 동의를 받아야 하는지.
3. **누락 가능성 고지**: "일부가 가려지지 않을 수 있어요"로 충분한지. 가려지지 않은 채 외부로 나갔을 때의 책임 문구.
4. **외부 AI의 학습 이용**: 외부 서비스가 이미지를 학습에 쓰지 않도록 계약·설정(무료 키는 학습에 쓰일 수 있음)을 확인하고, 그 내용을 문구에 넣을지.
5. **선택 동의의 범위**: "서비스 개선·새 기능 개발 활용"이 너무 넓지 않은지. 보관 기간을 정해서 적어야 하는지. 동의 철회 방법(삭제 요청)을 어디에 안내할지.
6. **분석 결과 보관 기간**: 영상은 지워도 결과가 DB에 남는다. 보관 기간을 문구에 넣을지, 사용자가 삭제할 수 있게 할지.
7. **필수/선택 분리**: 분석 동의(필수)에 외부 전송, 영상 삭제 안내, 면책(법적 효력 없음)이 함께 묶여 있다. 항목별로 나눠 받아야 하는지.
8. **만 14세 미만·제3자**: 영상에 찍힌 제3자(상대 운전자, 보행자)의 동의는 따로 필요 없는지.
9. **법적 효력 없음 문구**: 서비스 화면의 다른 곳(결과 화면)에도 같은 고지가 있어야 하는지.
10. **이용약관·개인정보처리방침**: 동의 문구와 별도로 처리방침 페이지가 필요한지.

## 개발 쪽에서 맞춰야 할 것
- 문구가 바뀌면 `CONSENT_VERSION`을 올린다 (지금은 `2026-10-19.2`).
- 보관 기간을 바꾸면 `SESSION_TTL_HOURS`, `RETENTION_DAYS`, `UNSUPPORTED_RETENTION_HOURS`를 맞추고 문구(`ConsentModal.jsx`의 "2시간", "90일")도 고친다.
