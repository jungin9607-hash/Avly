## 2. 사용자 흐름 (확정)

```
영상 선택(1개) → 분석 동의(필수) [+ 영상 저장·추가 활용 동의(선택)]
→ 번호판·사람 비식별화 → AI 분석
→ 사고 상황 확인 (사고 장소 / 사고 유형 / 내 차 과정 / 상대 차 과정) → 가감요소 질문
→ 결과 (과실비율, 가감 근거) → 사고 타임라인 → 유사 판례 → (결과 저장·공유)
```

- 차대차가 아닌 사고로 판단되면 AI 분석 중간에 멈추고 안내합니다.
- 사고 상황 확인에서 사용자가 값을 고치면, 영상을 다시 분석하지 않고 규칙 계산만 다시 합니다.

## 4. 결과 화면이 보여줄 수 있는 것과 없는 것

### 보여줄 수 있는 것
- 과실 후보와 **기본 비율**, 적용 가능한 가감요소 (가감요소는 **133개 중 7개 유형만 등록**돼 있음)
- 사고 타임라인: **구간 단위**(시작~끝 초), 설명, 확실도 라벨, 근거 문장
- 사고 상황 요약 (장소, 유형, 내 차와 상대 차의 움직임)
- 유사 판례의 법원, 날짜, 사건번호, 요약, 출처 링크, **비교 한계 문구**
- 판례와 내 사고의 공통점·차이점 (규칙 기반이라 단순함)
- 텍스트 보고서

### 보여줄 수 없는 것 (화면과 문구에서 빼야 함)
| 항목 | 이유 |
| --- | --- |
| 속도, G값, 감속, 차간거리(m), 방향지시등 확률 | 모델이 측정하지 않음. 보정 없는 영상에서 속도 추정은 신뢰할 수 없음 |
| 충돌 시각과 접촉 좌표의 **확정** | 모델은 접촉이 확실할 때만 충돌 시점을 잡고, 아니면 "충돌 의심"으로만 표현함 |
| 판례 유사도 퍼센트(98.4% 등) | 통계적 의미가 있는 값을 계산할 수 없음. "같은 유형", "조건 5개 중 4개 일치" 같은 표시로 대체 |
| 판례별 상세(사건 개요, 경위, 가감 근거) | 협회 도표 요약에는 없음. 법령 API로 가져온 판례는 판시사항·판결요지만 있음 |
| 항상 존재하는 단일 최종 비율 | 확정할 수 없는 경우가 정상 동작임 |

### 과실 결과의 상태 (화면 설계에 필요)
1. **확정**: 가감요소까지 반영한 최종 비율이 있음
2. **기본값만**: 맞는 유형은 찾았지만 가감요소가 등록되지 않은 유형 (대부분의 유형이 여기에 해당)
3. **후보 여러 개**: 조건이 확인되지 않아 후보가 둘 이상
4. **확정 불가**: 표에 맞는 유형이 없음. AI가 상황을 서술하고 가장 가까운 유형을 참고용으로만 보여줌

## 5. 데이터 범위와 한계

| 항목 | 현황 |
| --- | --- |
| 과실표 | 133개 유형 (차대차) |
| **가감요소** | **7개 유형만 등록** (7/133, 약 5%). 나머지는 공식 문서에서 추출해서 입력해야 함. 사람이 검수해야 하고, 숫자가 틀리면 과실비율이 틀림. 공식 문서의 이용 조건 확인 필요 |
| 판례 | 협회 도표의 요약을 수작업으로 입력한 5개 유형 + 법령 API로 보충. API로 가져온 판례는 검수 전 상태로 시작 |
| 법령 | 법령 API로 조문 조회. 조문별 쉬운 풀이는 3개만 작성됨 |
| 분석 정확도 | **측정한 적 없음.** 정답 라벨이 있는 평가용 영상이 없음 |
| 저장된 분석 결과 | 4건뿐이고 영상 2개는 특정 영상에 맞춘 보정이 적용된 상태라 대표성이 없음 (유형 연결 2건, 참고용만 1건, 연결 실패 1건) |

## 6. 개인정보, 동의, 보관

**결정된 것**
- 분석 동의는 필수, 영상 저장·추가 활용 동의는 선택
- 번호판은 검은 박스, 사람은 전체 블러로 자동 처리. 소리는 처리 결과에 포함하지 않음
- 원본은 세션 종료 시 삭제, 저장 동의 시 비식별본만 보관, 동의하지 않으면 비식별본도 삭제하고 분석 결과(JSON)만 남김
- 프레임 이미지는 저장하지 않음 (결과는 프레임 번호와 초 단위 시각만 담고, 장면은 보관한 영상에서 뽑음)
- 영상을 보관하지 않으면 타임라인 영상은 사용자가 자기 파일을 다시 선택해서 재생 (지금 화면에 있는 기능)

**법무·기획 확인이 필요한 것**
1. **외부 AI 전송 고지**: 비식별 프레임 이미지가 외부 AI 서비스(OpenAI 또는 Google)로 전송됨. 국외 이전에 해당할 수 있음. 지금 동의 문구는 "일시적 영상 전송"까지만 언급
2. **Gemini를 쓸 경우 유료 티어 필수**: 무료 티어는 입력 내용을 구글 제품 개선에 사용한다고 문서에 명시되어 있음
3. **자동 비식별의 한계 고지**: 멀거나 어둡거나 일부만 보이는 번호판과 사람은 놓칠 수 있음. 동의창과 결과 화면에 알려야 함
4. **화면 문구와 실제 불일치**: 이전 동의창은 "보행자 얼굴 블러링"과 "텔레메트리"를 언급했으나 둘 다 해당하지 않음. 텔레메트리 문구는 삭제했고, 사람 블러는 구현됨
5. **영상 접근 제어**: 로그인이 없어서 소유 토큰(`session_id`)이 유일한 제어 수단. **현재 서버는 업로드 폴더 전체를 누구나 접근하게 열어 둠** (원본이 URL만 알면 보임). 서명 URL로 바꿔야 함
6. **공유 링크**: 소유 토큰이 없는 사람은 결과를 못 보므로, 공유 기능을 둘지, 둔다면 어떤 정보를 공유할지 정해야 함
7. 보관 기간 (원본 세션의 정의, 비식별본 보관 기간), 수집 동의 기록 수준(버전과 시각만 vs IP·기기 정보)

## 7. 비기능 요구에 참고할 수치

| 항목 | 내용 |
| --- | --- |
| 처리 시간 | **측정하지 못함.** 비식별화(번호판 + 사람, 프레임마다 탐지 모델 2개)와 AI 3단계가 합쳐지므로 분 단위일 수 있음. 비식별화 시간은 영상 길이와 서버 사양에 비례 |
| AI 호출 | 영상 1건당 최대 4번(전체 흐름, 상세 확인, 차선 원인 확인, 유형 비교). 영상이 20초 이하이면 프레임 수에 상한이 있어 비용이 영상 길이에 비례해 늘지 않음 |
| 건당 AI 비용 (**추정**) | 저장된 실행 기록의 토큰(입력 약 3.9만, 출력 약 3.9천)과 공개 단가로 계산. GPT-4.1 약 120원, Gemini Flash-Lite 계열 약 22~30원, Gemini 3.8 Flash 약 62원(2027년부터 약 124원). 1달러=1,400원 가정. **Gemini는 토큰을 다르게 세므로 실측 필요**. 과실표가 133행으로 줄어 유형 비교 단계 입력이 더 줄어들 것 |
| 동시 처리 | 현재 분석 코드는 한 프로세스에서 **하나씩만** 실행 가능 (공유 상태 때문). 여러 사용자를 동시에 받으려면 코드 변경이 필요 |
| 외부 의존 | AI 서비스(OpenAI 또는 Google), 법령 API(인증키), 모델 가중치 다운로드(첫 실행 시) |
| 서버 요구 | ffmpeg, PyTorch(번호판·사람 탐지, 이미지 용량이 큼), 영상과 결과를 저장할 객체 저장소 |
| 가용성 | AI나 법령 API가 실패했을 때: 판례 조회 실패는 분석을 계속하고, AI 호출 실패는 분석 실패로 처리 (재시도 정책은 미정) |

## 8. 성공 지표 제안 (제안일 뿐 결정된 것이 아님)

| 지표 | 측정 방법 |
| --- | --- |
| 분석 완료율 | 완료 / (완료 + 실패), 지원하지 않는 사고는 별도 집계 |
| 지원 범위 밖 비율 | `unsupported` 비율. 높으면 범위 확장 근거 |
| 처리 시간 | 영상 업로드부터 사고 상황 확인 화면까지, 중앙값과 95퍼센타일 |
| 건당 AI 비용 | 단계별 호출 기록(`analysis_stage_log`)의 토큰 합계 |
| 비식별 누락률 | 표본 영상을 사람이 검수 |
| 분석 정확도 | 팀이 라벨링한 평가 영상 대비 장소·유형·내 차/상대 차 과정 일치율 |
| 사용자 수정률 | 사고 상황 확인에서 사용자가 AI의 판단을 고친 비율 |
| 가감요소 커버리지 | 가감요소가 등록된 유형 비율 (지금 7/133) |

## 9. 아직 정해야 할 것 (우선순위 순)

1. **정확도 평가용 영상 10~20개와 정답 라벨.** 모델 교체(GPT ↔ Gemini) 판단과 품질 보증에 필요
2. **가감요소 확장 범위**와 공식 문서 이용 조건, 검수 담당자 (5% → 어디까지)
3. **동의 문구**(외부 AI 전송, 국외 이전, 저장 동의, 자동 비식별의 한계)와 법무 확인
4. 결과 화면의 **네 가지 상태**(확정, 기본값만, 후보 여러 개, 확정 불가) 디자인
5. **영상 보관 기간**, 세션의 정의, 지원하지 않는 사고의 영상 처리
6. 공유 기능 유지 여부
7. 서버 PDF 필요 여부 (필요하면 한글 폰트와 라이선스, 저장 위치, 법적 고지 확정)
8. 영상 길이를 업로드 전에 확인할지
9. 사고 대상 판단이 틀렸을 때(차대차를 보행자로 오판) 사용자가 되돌릴 방법
10. 사고 상황 확인 화면을 4개 항목 카드 하나로 할지, 단계별로 할지
