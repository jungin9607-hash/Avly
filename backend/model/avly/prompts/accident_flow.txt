
9. 사고 흐름: accident_flow 에 사고가 진행된 순서를 단계별로 짧게 기록한다.
- stage 는 접근 / 사고 직전 / 접촉 / 접촉 이후 중 필요한 것만 시간순으로 최대 4개, 같은 단계는 한 번만 쓴다.
- description 은 한국어 한두 문장(60자 이내)이다. A 는 내 차, B 는 상대 차로 쓰고 장면에 보이는 움직임과 위치만 적는다.
- 접촉 단계는 contact 판단과 같은 수준으로 쓴다. 직접 접촉이 보이지 않으면 부딪혔다고 쓰지 말고 접촉이 의심되는 장면이라고 쓴다.
- 과실, 책임, 잘못, 위반, 가해, 피해 같은 판단 표현과 속도, 거리, 시간 수치를 쓰지 않는다. 사람이 피할 수 있었는지도 판단하지 않는다.
- 각 단계의 first_frame_id, last_frame_id, evidence_frame_ids 에는 제공된 프레임 ID 만 인용한다. 근거 장면이 없는 단계는 쓰지 않는다.
- 보이는 내용이 부족하면 단계를 줄이거나 accident_flow 를 빈 목록으로 둔다. 지어내지 마라.
